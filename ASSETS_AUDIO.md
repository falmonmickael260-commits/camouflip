# Provenance audio

Tous les fichiers audio utilisés par le jeu sont stockés localement. `assets/source-audio/` contient les originaux OGG, WAV ou MP3 et les archives sources ; `public/audio/` contient leurs conversions AAC (`.m4a`) pour le navigateur et les futurs tests iOS/Android. Les originaux ne sont pas chargés par le client web.

Les fichiers Kenney proviennent du [miroir des packs Kenney](https://github.com/ETdoFresh/kenney.nl) ; les deux anciennes boucles proviennent du [répertoire de musique du jeu Super Bash Folds](https://github.com/blancmathis/Super_Bash_Folds/tree/main/public/assets/audio/open/music), dont le [registre de licences](https://github.com/blancmathis/Super_Bash_Folds/blob/main/public/assets/audio/LICENSES.md) les rattache à la publication originale de qubodup. Les nouveaux originaux OGG et les packs de bruitages ont été téléchargés directement depuis leurs pages OpenGameArt ci-dessus. Les fichiers AAC du jeu sont des conversions locales, avec égalisation et niveau sonore adaptés au mixage mobile. Les deux anciennes boucles restent dans le dossier comme sources de repli mais ne sont plus chargées par le jeu.

Kenney indique que ses packs CC0 sont réutilisables commercialement sans attribution obligatoire ; la mention des auteurs ci-dessus est conservée pour la traçabilité. Aucune musique ni aucun bruitage d'un jeu commercial existant n'a été copié.
